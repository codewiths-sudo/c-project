# C Programming Projects Collection

A structured collection of CLI-based applications and text-based games written in C.

---

## Projects

| Project | Description |
| :--- | :--- |
| **ATM Simulator** | A simple ATM simulation supporting balance checking, deposits, and withdrawals. |
| **Console Calculator** | A console-based calculator for performing basic arithmetic operations. |
| **Escape From Station X-99** | A sci-fi text-based adventure game set in space. |
| **Rock Paper Scissors** | A classic Rock-Paper-Scissors game playable in the terminal. |
| **The Galactic Hacker** | A space and hacking-themed interactive CLI mini-game. |
